# Hello Kitty 26

Одностраничный сайт-био для IRL Telegram-канала **Hello Kitty**.

## Что внутри

- тёмная визуальная тема с бордово-красной палитрой;
- анимированные световые дуги на фоне;
- плавно покачивающееся изображение Hello Kitty в первом блоке;
- фиксированная боковая навигация по секциям;
- автоматическое выделение активной секции при прокрутке;
- блок «О нас» и карточки с описанием канала;
- кнопка перехода в Telegram-канал;
- адаптивная версия для мобильных устройств;
- поддержка `prefers-reduced-motion` для пользователей, отключающих анимации.

## Файлы

- `index.html` — структура страницы;
- `styles.css` — стили, адаптивность и анимации;
- `script.js` — активная навигация при прокрутке;
- `photo_2026-10-23_18-38-00.png` — основное изображение;
- `photo_2026-10-23_20-49-58.jpg` — фотография в блоке «О нас»;
- `favicon.png` и `favicon.ico` — круглая иконка сайта из основного фото.
